Dijkstra's Algorithm

Always expands the node with the smallest known distance from the source — a greedy approach that provably finds the shortest path in any graph with non-negative edge weights.

⏱ Time: O((V+E) log V) 📦 Space: O(V) Non-negative weights
🧭
Greedy Shortest Path
Dijkstra always picks the cheapest unvisited node — a greedy strategy that provably finds the optimal path for all non-negative weights.

Overview
🧭
Think of it as a GPS navigator
Imagine planning the cheapest flight from city S to city T. You wouldn't just count the number of stops — you'd compare total ticket costs. Dijkstra works the same way: it always explores the city with the lowest cumulative cost so far, updating estimated costs whenever a cheaper route is found. Once a city is "settled", its cost is guaranteed optimal.
Min-Priority Queue Greedy Strategy Edge Relaxation Invented: 1956 by Edsger Dijkstra
🔷
Why not just use BFS on a weighted graph?
BFS treats every edge as cost-1. If S→A costs 100 and S→B→A costs 2+1=3, BFS would return S→A (1 hop) as the "shortest" path. Dijkstra respects actual weights — it would correctly find S→B→A (total cost 3) as the cheapest route.
Core Concept

Edge Relaxation — The Heart of Dijkstra

"Relaxing" an edge (u→v) means asking: "Is travelling through u cheaper than my current best estimate for v?"

⚡
Relaxation Formula
if dist[u] + weight(u,v) < dist[v]:
    dist[v] = dist[u] + weight(u,v)
    prev[v] = u   // record the path
🔑
Why "relaxation"?
The term comes from loosening a constraint. Initially dist[v]=∞ (very tight, conservative). Each time we relax the edge (u,v), we loosen the bound — allowing a shorter estimate. Eventually dist[v] converges to the true shortest path.
Relaxation Example

Best route: S→B(2)→A(+1=3)→T(+5=8). Direct S→A would cost 4+5=9.

Algorithm Steps

How Dijkstra Works — Step by Step

  1. Initialise distances: Set dist[source]=0. Set dist[all other nodes]=∞. Create an empty previous-node map.
  2. Create min-heap: Insert the source with priority 0. All other nodes start with priority ∞.
  3. Extract minimum: Pop the node u with the smallest distance from the heap. This is the next node to settle.
  4. Skip if settled: If u was already processed (settled), skip it. This handles stale heap entries from lazy deletion.
  5. Relax all neighbours: For each neighbour v of u: if dist[u]+weight(u,v) < dist[v], update dist[v] and push v into the heap with the new, lower priority.
  6. Repeat: Go back to step 3 until the heap is empty. Every node now has its optimal shortest distance from the source.
  7. Reconstruct path (optional): Follow prev[v] back from target to source to reconstruct the actual shortest path.
🔑
Why Dijkstra's Greedy Choice is Always Safe
When we extract node u (minimum distance), its distance is already optimal. Why? Because:

1. Every other node in the heap has dist ≥ dist[u] (min-heap property).
2. All edge weights are non-negative.
3. Therefore, no future path through unprocessed nodes can make u cheaper.

This is exactly why negative weights break Dijkstra — a negative edge could let us "go back" and find a cheaper path to an already-settled node.

Implementation

Python Code

PythonDijkstra — Full Implementation
import heapq

def dijkstra(graph, start):
    # graph = {node: [(nb, weight), ...]}
    dist = {n: float('inf') for n in graph}
    prev = {n: None for n in graph}
    dist[start] = 0
    heap = [(0, start)]  # (cost, node)

    while heap:
        cost, u = heapq.heappop(heap)  # extract min
        if cost > dist[u]:
            continue  # stale entry, skip

        for v, w in graph[u]:
            nd = dist[u] + w   # tentative distance
            if nd < dist[v]:   # relaxation
                dist[v] = nd
                prev[v] = u
                heapq.heappush(heap, (nd, v))

    return dist, prev
PythonReconstruct Shortest Path
def get_path(prev, target):
    """Reconstruct path from source to target."""
    path = []
    cur = target
    while cur is not None:
        path.append(cur)
        cur = prev[cur]
    return path[::-1]  # reverse to get src→target

# --- Example usage ---
graph = {
    'S': [('A',4), ('B',2)],
    'A': [('T',5)],
    'B': [('A',1), ('T',8)],
    'T': [],
}

dist, prev = dijkstra(graph, 'S')
print(dist)        # {'S':0,'A':3,'B':2,'T':8}
print(get_path(prev, 'T'))  # ['S','B','A','T']

# Time:  O((V+E) log V)  with binary heap
# Space: O(V)  for dist + prev arrays
Limitations & Variants

When Dijkstra Fails & What to Use Instead

❌
Dijkstra fails with negative weights
If any edge has a negative weight, a "settled" node might later get a cheaper path found — breaking the greedy guarantee. Example: S→A(3), S→B(5), B→A(-4). Dijkstra settles A at cost 3, but the true shortest is S→B→A = 5+(−4) = 1. Use Bellman-Ford for negative weights.
📊
Choosing the right algorithm
Unweighted graph: BFS — O(V+E)
Weighted, no negatives: Dijkstra — O((V+E) log V)
Negative weights: Bellman-Ford — O(VE)
Need a heuristic: A* — faster with good h(n)
All pairs: Floyd-Warshall — O(V³)
