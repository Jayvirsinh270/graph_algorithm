Depth-First Search

DFS plunges as deep as possible down one branch before backtracking to explore others. It's the foundation of cycle detection, topological sort, and maze solving.

⏱ Time: O(V + E)📦 Space: O(V)Data Structure: LIFO Stack
🌿
Deep-First Exploration
DFS uses a LIFO stack (or call stack via recursion) — diving as deep as possible on each branch before backtracking.

Intuition
🌿
Think of exploring a maze
You enter a maze and always choose the first available corridor. You walk as far as you can until you hit a dead end — then you backtrack to the last junction and try the next path. DFS does exactly this: dive deep along one branch, hit a dead end, backtrack, try another direction. The call stack (or explicit stack) keeps track of exactly where to backtrack to.
🌿 One branch at a time ↩️ Backtracking Stack = path memory
🟣
Why a Stack (LIFO)?
A stack stores the path from root to current node. When you go deeper, you push nodes. When you hit a dead end and pop, you automatically return to the last junction. Recursion uses the program's own call stack for this — which is why recursive DFS code is so short.
⚠️
DFS does NOT guarantee shortest path
DFS may reach a node via a long detour when a shorter path exists. It depends on the order neighbours are explored. Use BFS for shortest unweighted paths, Dijkstra for weighted paths.
Algorithm Steps

How DFS Works — Step by Step

Iterative (Stack) Version

  1. Initialise: Push the start node onto the stack. Create an empty visited set.
  2. Pop: Remove the top node from the stack.
  3. Check visited: If already visited, skip it and go back to step 2.
  4. Mark & process: Mark the node visited. Record it in the traversal order.
  5. Push neighbours: Push all unvisited neighbours onto the stack.
  6. Repeat: Go to step 2 until the stack is empty.

Recursive Version

  1. Base case: If the node is already visited, return immediately.
  2. Mark visited: Add current node to the visited set.
  3. Process: Record or act on the current node.
  4. Recurse: For each unvisited neighbour, call DFS recursively.
  5. Backtrack: When the recursion returns, you're automatically back at the previous node — no manual stack management needed.
💡
Recursive = Iterative with implicit stack
Both versions produce the same result but may differ in exact traversal order depending on neighbour processing order.

Python Code — Three Versions

PythonRecursive DFS
def dfs_recursive(graph, node, visited=None):
    if visited is None: visited = set()
    visited.add(node)           # ① mark
    print(node)                 # ② process
    for nb in graph[node]:
        if nb not in visited:
            dfs_recursive(graph, nb, visited)
    # ③ backtrack = function returns here
    return visited

# Iterative DFS (explicit stack)
def dfs_iterative(graph, start):
    visited, stack, order = set(), [start], []
    while stack:
        node = stack.pop()      # LIFO
        if node not in visited:
            visited.add(node)
            order.append(node)
            for nb in graph[node]:
                if nb not in visited:
                    stack.append(nb)
    return order
PythonDFS — Cycle Detection & Topo Sort
# Cycle detection in directed graph
def has_cycle(graph, node, visited, in_stack):
    visited.add(node); in_stack.add(node)
    for nb in graph[node]:
        if nb not in visited:
            if has_cycle(graph, nb, visited, in_stack):
                return True
        elif nb in in_stack:
            return True   # back edge = cycle!
    in_stack.discard(node)
    return False

# Topological sort (DFS post-order)
def topo_sort(graph):
    visited, result = set(), []
    def dfs(node):
        visited.add(node)
        for nb in graph[node]:
            if nb not in visited:
                dfs(nb)
        result.append(node)     # post-order
    for node in graph:
        if node not in visited:
            dfs(node)
    return result[::-1]      # reverse = topo order
3. Applications

Where DFS is Used

🔄

Cycle Detection

DFS detects cycles in directed graphs using a "currently in stack" flag. If you encounter a node already in the current path — cycle found!

📦

Topological Sorting

DFS post-order (reversed) gives a valid topological ordering of a DAG — used by npm, pip, Maven for dependency resolution.

🧩

Maze Solving & Backtracking

DFS with backtracking is the classic maze-solving algorithm. Also used in Sudoku solvers and N-Queens puzzles.

🏔️

Connected Components

Run DFS from each unvisited node to find and label all connected components in an undirected graph.

🔀

Strongly Connected Components

Kosaraju's and Tarjan's SCC algorithms are both built on two passes of DFS — critical for compiler analysis and web link graphs.

🎨

Bipartite Check

DFS with 2-colouring checks if a graph is bipartite (can be split into two groups with no edges within a group).

DFS Application: Topological Sort

In a DAG, DFS post-order (reversed) gives a valid task execution order — every dependency appears before the task that needs it.
